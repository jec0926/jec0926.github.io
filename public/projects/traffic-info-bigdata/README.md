# 교통정보 빅데이터 프로젝트 이미지 추가 위치

이 폴더는 홈페이지의 `도로교통공단 교통정보 빅데이터화 및 제보접수 시스템 구축` 프로젝트 카드에서 사용하는 이미지 위치입니다.

아래 파일명으로 이미지를 추가하면 별도 코드 수정 없이 홈페이지에 반영됩니다.

- `cover.png`: 프로젝트 카드 대표 이미지
- `detail-1.png`: 상세 모달 첫 번째 이미지
- `detail-2.png`: 상세 모달 두 번째 이미지
- `detail-3.png`: 상세 모달 세 번째 이미지

권장 구성:

- `cover.png`: 프로젝트 전체 개요 또는 시스템 화면 대표 이미지
- `detail-1.png`: 제보접수/조회 화면
- `detail-2.png`: 데이터 구조화 또는 DB 흐름도
- `detail-3.png`: 결과 화면, 다운로드 기능, 운영 프로세스 요약

기관 내부 정보, 개인정보, 비공개 데이터가 보이는 화면은 마스킹하거나 재구성한 이미지로 교체해 주세요.
