# 비욘드아이앤씨 홈페이지 리뉴얼 PM 이미지 추가 위치

이 폴더는 홈페이지의 `비욘드아이앤씨 기업 홈페이지 리뉴얼 PM` 프로젝트 카드에서 사용하는 이미지 위치입니다.

아래 파일명으로 이미지를 추가하면 별도 코드 수정 없이 홈페이지에 반영됩니다.

- `cover.png`: 프로젝트 카드 대표 이미지
- `detail-1.png`: 상세 모달 첫 번째 이미지
- `detail-2.png`: 상세 모달 두 번째 이미지
- `detail-3.png`: 상세 모달 세 번째 이미지

권장 구성:

- `cover.png`: 현재 비욘드아이앤씨 홈페이지 메인 화면
- `detail-1.png`: 서비스/사업 소개 페이지 화면
- `detail-2.png`: 정보 구조 또는 리뉴얼 전후 구성 요약
- `detail-3.png`: PM 역할, 일정, 요구사항 정리 산출물 요약

내부 일정표, 비공개 회의자료, 개인 연락처가 포함된 화면은 마스킹하거나 재구성한 이미지로 교체해 주세요.
