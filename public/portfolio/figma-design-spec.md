# Portfolio Deck Figma Spec

## Frame

- Size: 1920 x 1080
- Grid: 12 columns
- Margin: 96
- Gutter: 24
- Background: #050505

## Colors

- Background: #050505
- Panel: #121312
- Panel Deep: #0B0C0B
- Border: #30352F
- Text Primary: #F8FAFC
- Text Muted: #AEB6AE
- Text Dim: #6F776D
- Accent Sage: #CFD8C8

## Typography

- Font: Malgun Gothic or Pretendard
- Slide Label: 15 / Bold / uppercase
- Title: 46-70 / Bold
- Question: 24 / Bold
- Panel Heading: 23 / Bold
- Body: 17-18 / Regular
- Diagram Node: 20-24 / Bold

## Case Slide Layout

- Header area: x 96, y 140-385
- Narrative panel: x 96, y 185, w 610, h 515
- Diagram panel: x 760, y 185, w 1064, h 515
- Footer page number: right 96, bottom 38

## Components

- Narrative Panel
  - Issue
  - What I Structured
  - Output
- Diagram Panel
  - Architecture flow
  - Scorecard
  - Index blocks
  - Matrix
  - Governance flow
  - Diagnosis flow
  - Driver tree
  - Before / After
  - Test grid
  - Cadence timeline
  - Data pipeline
  - Business system

## Design Rule

- Do not use protected screenshots.
- Explain each project with a business question, structured logic, and output.
- Keep diagrams abstract enough for public sharing.
- Use one narrative panel consistently, and vary only the logic diagram by project type.
